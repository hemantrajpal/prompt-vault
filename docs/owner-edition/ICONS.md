# Iconsax integration

Icons by [Iconsax](https://iconsax.io/), sourced from the official [Iconsax repository](https://github.com/lusaxweb/iconsax) at e5dba15361f69d34d0f3f3f35408a28fe74c5727, linked by Iconsax documentation. The app embeds a functional subset of Free linear SVG icons in src/_Icons.html; it does not redistribute a standalone icon collection.

Icons remain subject to the [Iconsax Free License](https://docs.iconsax.io/license-and-terms/license), independently of this app's MIT code license. Authorship remains Iconsax. Original stroke colors are adapted to currentColor for accessible theme inheritance. This notice must remain with the integrated code.

No icon CDN or runtime account/key is needed. All SVGs are trusted bundled constants; user text never becomes icon markup.
